# 噪声红线（法定合规）

> 管企业。来源：GB 12523-2025（2026年1月1日实施，代替GB12523-2011）

## 施工场界噪声排放限值

| 时段 | 限值 |
|---|---|
| 昼间（6:00-22:00） | 70 dB(A) |
| 夜间（22:00-次日6:00） | 55 dB(A) |

## 夜间峰值要求

夜间噪声最大声级超过限值的幅度不得高于15 dB(A)
→ 即夜间瞬时峰值不得超过70 dB(A)

## 夜间施工要求

- 夜间禁止产生噪声的建筑施工作业
- 因特殊需要必须连续作业的，须有县级以上人民政府或其主管部门证明
- 并必须公告附近居民

## 测点位置

- 一般：场界外1m，高度1.2m以上
- 场界距敏感建筑物较近时：可在敏感建筑物室内测量，限值减10 dB(A)

## 判定规则（红线）

```
IF 时间∈[6:00,22:00] AND 场界噪声 > 70 → 昼间红线超标
IF 时间∈[22:00,6:00] AND 场界噪声 > 55 → 夜间红线超标
IF 夜间瞬时峰值 > 70 → 夜间峰值超标
IF 夜间施工无主管部门证明 → 夜间施工违规
```
