# 安全管理与人员配置

> 来源：建质规〔2025〕3号（2026年3月26日实施）、安全生产法

## 专职安全员配备硬指标

### 按建筑面积配备（建筑工程/装修工程）

| 建筑面积 | 最少专职安全员 |
|---|---|
| 1万㎡以下 | 1人 |
| 1万~5万㎡ | 2人 |
| 5万㎡以上 | 3人，每增5万㎡加1人 |

### 按合同价配备（市政工程）

| 合同价 | 最少专职安全员 |
|---|---|
| 5000万以下 | 1人 |
| 5000万~1亿 | 2人 |
| 1亿以上 | 3人，每增5000万加1人 |

### 需配安全总监的项目
- 现场人员峰值>500人
- 房屋建筑工程>10万㎡
- 市政合同价>4亿 / 隧道地铁>4km

## 智能体辅助管理逻辑

```
输入：建筑面积/合同价, 现场人数

IF 建筑面积=3万㎡ → 应配2名专职安全员
IF 现场人员=600人 → 应配安全总监+独立安全管理机构

系统自动生成：
- 当前项目最低人员配置要求
- 建议巡检频次
- 覆盖缺口提示
```
