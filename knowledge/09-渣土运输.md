# 渣土运输与建筑垃圾

> 管企业。来源：西安建筑垃圾管理规定、六个100%

## 识别项（视觉）

- **渣土车未密闭**：车厢未盖篷布或篷布破损
- **渣土车超载**：货物高出车厢挡板
- **车轮带泥**：轮胎沾泥上路
- **乱倒渣土**：工地外随意倾倒
- **未冲洗**：出场车辆未冲洗轮胎

## 判定规则

```
IF 渣土车未密闭运输 → 🔴 红线违规
IF 车辆带泥上路 → 🔴 红线违规
IF 出场未冲洗 → 🔴 红线违规
IF 无消纳证 → 🟠 违规
```

## 国家要求

- 渣土车必须密闭运输
- 必须有消纳证
- 必须按指定路线行驶
- 必须按指定时间运输
- 出场必须冲洗轮胎和车身

## 处置建议

- 未密闭：禁止出场
- 带泥：重新冲洗
- 无消纳证：联系管理部门
