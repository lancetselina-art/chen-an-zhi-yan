# 噪声黄线（工人听力保护）

> 管工人。来源：GBZ 2.2-2007 第9章 噪声职业接触限值

## 职业接触限值（8小时时间加权）

| 日接触时间 | 接触限值 dB(A) |
|---|---|
| 5天/周，8h/天 | 85 |
| 4h/天 | 88 |
| 2h/天 | 91 |
| 1h/天 | 94 |

**规则**：接触时间每减半，限值增加3 dB(A)。

## 场界→作业面噪声推算

工人在作业面离声源近，实际听到的噪声 ≈ 场界噪声 + 10~15 dB

| 场界噪声 | 作业面估算 | 判定 |
|---|---|---|
| ≤70 dB(A) | 80-85 dB(A) | 🟡 黄线边缘，建议戴耳塞 |
| 75 dB(A) | 85-90 dB(A) | 🟠 黄线超标，必须戴耳塞 |
| 80 dB(A) | 90-95 dB(A) | 🔴 严重超标，强制防护+轮岗 |

## 判定规则（黄线）

```
作业面噪声 ≈ 场界噪声 + 12 dB（中值）

IF 作业面噪声 ≥ 85 → 🟠 黄线超标（噪声性耳聋风险）
IF 作业面噪声 ≥ 90 → 🔴 必须佩戴耳塞耳罩，缩短接触时间
```

## 防护要求

- 作业面噪声>85 dB(A)：必须佩戴耳塞或耳罩
- 噪声>90 dB(A)：轮岗，每人每天接触不超过2小时
- 定期听力检查
