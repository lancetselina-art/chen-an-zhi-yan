# 安全帽/口罩识别规则

> 视觉识别+处置流程。来源：《建筑施工安全检查标准》JGJ59、防暑降温办法、GBZ2.1

## 安全帽识别

### 识别项
- **未佩戴**：头部无安全帽
- **佩戴不规范**：帽带未系、帽体歪斜、未完全扣合
- **正确佩戴**：帽体扣紧、帽带系于下颌

### 处置流程
```
检出未佩戴 → 确认在作业区域（排除休息区/办公区）
  ↓
一级：现场语音提示（首次提示不留违规记录）
  ↓ 5秒后回检
  ├─ 已纠正 → 记录"提示后自行纠正"，闭环
  └─ 未纠正 → 再次提示，升级二级
      ↓ 2分钟后回检
      ├─ 已纠正 → 记录"管理介入后纠正"
      └─ 未纠正 → 三级：生成整改工单
```

## 口罩识别

### 识别项
- **未佩戴**：面部无口罩
- **佩戴不规范**：口罩挂下巴、未遮住口鼻
- **正确佩戴**：完全覆盖口鼻、鼻夹压紧

### 口罩类型建议
- 普通防尘：KN90（日常低粉尘环境）
- 高粉尘（土方/切割）：KN95
- 焊接：专用防尘口罩+通风
- 防病毒：医用外科

### 处置流程（结合粉尘浓度）
```
检出未戴口罩
  ↓
IF 当前粉尘浓度 > 黄线 → 优先语音提示"粉尘浓度较高，请佩戴口罩"
IF 当前粉尘浓度正常 → 语音提示"请佩戴口罩，注意呼吸健康"
  ↓ 回检
  ├─ 已佩戴 → 闭环
  └─ 未佩戴 → 推送现场管理人员
```

## 提示语库（预审，不允许AI即兴生成）

### 安全帽
- "工友您好，请佩戴好安全帽，注意头部安全。"
- "您好，看到您安全帽帽带没系好，请系紧一下，谢谢。"

### 口罩
- "工友您好，当前区域粉尘较多，请规范佩戴口罩，注意呼吸健康。"
- "您好，口罩请遮住口鼻效果更好，谢谢配合。"

### 高温
- "当前气温较高，请注意防暑，休息区已备好饮用水。"
- "气温较高，请大家注意轮换休息。"

### 扬尘
- "当前区域扬尘较大，请启动喷淋降尘。"
- "注意湿法作业，保持地面湿润。"

## 提示频次控制

- 同一提示对同一目标：5分钟内不超过2次
- 同一区域1小时内：不超过4次
- 夜间22:00-6:00：静音模式，仅控制台提示
