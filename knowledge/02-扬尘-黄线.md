# 扬尘黄线（工人健康预警）

> 管工人，长期接触会得职业病。来源：GBZ 2.1-2019 表2 粉尘职业接触限值

## 作业面呼吸带粉尘PC-TWA限值（8小时时间加权平均）

### 矽尘（最危险，土建主要粉尘）

| 游离SiO₂含量 | 总尘PC-TWA | 呼尘PC-TWA | 职业病 |
|---|---|---|---|
| 10%~50% | 1 mg/m³ | 0.7 mg/m³ | 矽肺 |
| 50%~80% | 0.7 mg/m³ | 0.3 mg/m³ | 矽肺 |
| >80% | 0.5 mg/m³ | 0.2 mg/m³ | 矽肺 |

### 水泥粉尘（主体/装饰阶段）

| 类型 | 总尘PC-TWA | 呼尘PC-TWA | 职业病 |
|---|---|---|---|
| 水泥粉尘（游离SiO₂<10%） | 4 mg/m³ | 1.5 mg/m³ | 水泥尘肺 |

### 其他常见粉尘

| 粉尘类型 | 总尘PC-TWA | 呼尘PC-TWA | 职业病 |
|---|---|---|---|
| 石灰石粉尘 | 8 mg/m³ | 4 mg/m³ | 尘肺 |
| 电焊烟尘 | 4 mg/m³ | — | 电焊工尘肺 |
| 碳化硅粉尘 | 8 mg/m³ | 4 mg/m³ | 尘肺 |
| 石墨粉尘 | 4 mg/m³ | 2 mg/m³ | 石墨尘肺 |
| 其他粉尘（未列名） | 8 mg/m³ | — | — |

## 场界→作业面呼吸带推算（经验系数，需现场验证）

> 说明：以下系数为工程经验估算，用于从场界TSP推算工人呼吸带浓度。
> 正式试点时应做现场个体采样校准。

| 作业类型 | 呼吸带 ≈ 场界TSP × | 主要粉尘 | 黄线（呼尘） |
|---|---|---|---|
| 土方开挖/拆除 | × 3~5 | 矽尘 | 0.7 mg/m³ |
| 混凝土搅拌/切割 | × 5~8 | 水泥尘 | 1.5 mg/m³ |
| 钢筋绑扎/普通作业 | × 1.5~2 | 混合尘 | 4 mg/m³ |
| 焊接/切割 | × 3~4 | 电焊烟尘 | 4 mg/m³ |
| 装修/安装 | × 1 | 混合尘 | 8 mg/m³ |

## 判定规则（黄线）

```
输入：场界TSP, 施工阶段, 作业类型

推算呼吸带 = 场界TSP × 作业系数

IF 作业类型=土方 AND 推算呼吸带 > 0.7 → 🟠 黄线超标（矽肺风险）
IF 作业类型=混凝土 AND 推算呼吸带 > 1.5 → 🟠 黄线超标（水泥尘肺）
IF 作业类型=焊接 AND 推算呼吸带 > 4 → 🟠 黄线超标（电焊尘肺）
IF 推算呼吸带 > 8 → 🔴 严重超标
```

## 黄线超标后的建议

- 必须佩戴KN95及以上防尘口罩
- 缩短连续作业时间（每2小时休息15分钟）
- 加强现场喷雾降尘
- 定期安排职业健康检查（胸片+肺功能）
