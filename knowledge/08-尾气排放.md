# 非道路移动机械尾气（黑烟识别）

> 管企业。来源：GB 20891-2014、西安非道路移动机械污染防治要求

## 识别项（视觉）

- **黑烟排放**：挖掘机、装载机、推土机、渣土车等冒黑烟
- **冒蓝烟/白烟**：机油燃烧或冷启动
- **无环保标识**：机械未贴环保标识牌

## 判定规则

```
IF 机械持续冒黑烟（>3秒）→ 🔴 红线违规
IF 机械无环保标识 → 🟠 违规
IF 高排放机械进入工地 → 🔴 违规
```

## 国家要求

- 非道路移动机械必须登记编码，悬挂环保标识
- 禁止使用超标排放机械
- 高排放机械禁止在城市建成区使用
- 工地应建立机械台账

## 处置建议

- 冒黑烟：立即停机检修
- 无标识：禁止进场
- 台账缺失：补登
