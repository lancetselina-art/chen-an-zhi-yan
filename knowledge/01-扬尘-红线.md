# 扬尘红线（法定合规）

> 管企业，违法就罚款停工。来源：《大气污染防治法》、GB 16297-1996、住建部六个100%

## 核心限值：施工场界颗粒物无组织排放

| 控制项目 | 限值 | 依据 |
|---|---|---|
| 颗粒物（TSP）无组织监控浓度 | ≤1.0 mg/m³ | GB 16297-1996 |
| 施工场界TSP小时平均（地方标准更严的从严执行） | 0.7~0.8 mg/m³ | 各地地标 |

> 说明：国家层面GB 16297规定颗粒物无组织排放监控浓度限值1.0 mg/m³；各地施工扬尘地标（如陕西DB61/1078、北京DB11/...）普遍更严，实际执行从严。

## 背景值修正方法

以最近城市监测点同时段PM10小时浓度为背景：

| 情况 | 判定 |
|---|---|
| TSP ≤ 1.3 × PM10背景 | 施工对环境基本无影响，直接对照限值 |
| 1.3×PM10 < TSP < 2×PM10 | 修正值 = TSP - 1.3×PM10，再对照限值 |
| TSP ≥ 2 × PM10背景 | 影响显著，立即报警 |

## 监测布点要求

- 点位：周界外浓度最高点（下风向10m范围内）
- ≤1万㎡：至少1个点；>1万㎡：至少2个点，每增1万㎡加1个
- 采样口距地面2.0~4.0m
- 必须配视频监控，具备超标抓拍

## 住建部"六个100%"（全国推行）

1. 工地周边100%硬质围挡
2. 物料堆放100%覆盖防尘网
3. 土方开挖100%湿法作业
4. 场内路面100%硬化
5. 出入车辆100%冲洗
6. 渣土车辆100%密闭运输

## 其他法定要求

- 施工现场应制定扬尘污染防治方案
- 易飞扬物料应密闭或覆盖
- 出口应设车辆冲洗设施
- 重污染天气红色预警：停止土石方、拆除、喷涂等涉气作业
- 冬季采暖季：城市建成区禁止土石方作业（按当地政府通知执行）

## 判定规则（红线）

```
IF 场界TSP > 1.0 mg/m³ → 红线超标（GB16297）
IF 场界TSP > 0.8 AND 施工阶段∈{拆除,土方,地基处理} → 红线超标（从严）
IF 场界TSP > 0.7 AND 施工阶段∈{基础,主体,装饰} → 红线超标（从严）
IF TSP > 2 × PM10背景 → 影响显著，立即报警
IF 无硬质围挡 → 红线违规
IF 裸土未覆盖 → 红线违规
IF 土方作业无湿法 → 红线违规
IF 出口无冲洗设施 → 红线违规
IF 夜间施工无证明 → 红线违规
```

## 罚则（《大气污染防治法》第115条）

- 未采取防尘措施：1万~10万罚款
- 拒不改正：责令停工整治
