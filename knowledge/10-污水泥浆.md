# 工地污水与泥浆

> 管企业。来源：水污染防治法、西安工地排水要求

## 识别项（视觉）

- **泥浆直排**：泥浆水直接排入市政管网或河道
- **无沉淀池**：工地未设三级沉淀池
- **污水横流**：工地积水未处理
- **油污泄漏**：机械漏油污染地面

## 判定规则

```
IF 泥浆直排市政管网 → 🔴 红线违规
IF 无沉淀池 → 🟠 违规
IF 油污泄漏未处理 → 🟠 违规
```

## 要求

- 工地必须设三级沉淀池
- 泥浆水必须沉淀达标后排放
- 严禁泥浆直排市政管网
- 机械维修区应设油污收集设施

## 处置建议

- 直排：立即封堵，补建沉淀池
- 油污：用吸油毡清理
- 沉淀池：定期清淤
