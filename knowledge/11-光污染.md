# 光污染与夜间施工照明

> 管企业。来源：建筑施工场界环境噪声排放标准配套要求、西安夜间施工管理

## 识别项（视觉）

- **夜间强光直射居民楼**：施工照明方向不对
- **夜间无遮挡施工**：夜间施工未做遮光措施
- **电焊弧光外泄**：焊接作业无遮光屏障

## 判定规则

```
IF 夜间施工照明直射居民楼 → 🟠 光污染投诉
IF 电焊作业无遮光 → 🟠 光污染
IF 夜间施工无主管部门证明 → 🔴 红线违规（同噪声红线）
```

## 要求

- 夜间施工照明应定向、遮光，避免直射居民
- 电焊作业应设遮光屏障
- 夜间施工必须有证明并公告附近居民

## 处置建议

- 调整照明方向
- 增设遮光板
- 夜间施工补手续
