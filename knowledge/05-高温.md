# 高温红线（法定作业时间+津贴）

> 管企业，法定要求。来源：《防暑降温措施管理办法》安监总安健〔2012〕89号

## 作业时间分级（第八条）

| 日最高气温 | 法定要求 |
|---|---|
| ≥40℃ | 停止当日室外露天作业 |
| 37℃~40℃ | 全天室外露天作业累计≤6小时；气温最高时段3小时内不得安排室外露天作业 |
| 35℃~37℃ | 换班轮休缩短连续作业时间；不得安排室外露天作业加班 |

## 其他法定要求

- 因高温停止工作、缩短工作时间，**不得扣除或降低工资**
- 不得安排怀孕女职工和未成年工在35℃以上高温天气从事室外露天作业
- 必须提供防暑降温饮料，不得以钱物替代
- 防暑降温饮料不得充抵高温津贴
- 高温工作场所应设休息场所（座椅+通风/空调）
- 35℃以上室外露天作业，或工作场所温度不能降至33℃以下，**必须发放高温津贴**

## 判定规则（红线）

```
IF 气温 ≥ 40℃ AND 有室外露天作业 → 🔴 违法，必须停工
IF 气温 ∈ [37,40) AND 室外作业累计 > 6h → 🔴 违法
IF 气温 ∈ [35,37) AND 安排加班 → 🟠 违规
IF 高温停止作业仍扣工资 → 🔴 违法
IF 35℃以上未发高温津贴 → 🔴 违法
```

## 简化WBGT对照（气温+相对湿度估算）

WBGT指数（湿球黑球温度）测量复杂，用气温+湿度简化估算：

| 气温 | 湿度50% | 湿度70% | 湿度90% |
|---|---|---|---|
| 30℃ | WBGT≈26 | WBGT≈28 | WBGT≈30 |
| 35℃ | WBGT≈31 | WBGT≈33 | WBGT≈35 |
| 38℃ | WBGT≈34 | WBGT≈36 | WBGT≈38 |
| 40℃ | WBGT≈36 | WBGT≈38 | WBGT≈40 |

> 重体力劳动WBGT≥25℃即为高温作业，≥28℃第三级以上。
