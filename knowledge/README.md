## 颜色分级

- 🔴 红线：违反国标/法规，必须立即整改，可能罚款停工
- 🟠 橙线：接近红线或黄线超标，预警+加强防护
- 🟡 黄线：工人健康风险，建议缩短作业时间/加强防护
- ✅ 合格：不显示

## 使用方式

app.py启动时自动读取本目录所有.md文件，拼接进system prompt。
新增文件按"序号-名称.md"命名即可，自动加载。

## 勘误记录

1. 噪声标准：GB12523-2011 → GB12523-2025（2026.1.1实施）
2. 空气标准：GB3095-2012 → GB3095-2026（2026.3.1实施）
3. 其他粉尘呼尘限值：GBZ2.1-2019中其他粉尘仅规定总尘8，无呼尘限值
4. 矽尘呼尘0.7 mg/m³：对应游离SiO₂ 10%~50%的情况
